# Foto profil

Taruh foto profil kontak demo di folder ini dengan nama file sesuai nama kontak:
`bu-sari.jpg`, `wulan.jpg`, `dimas.jpg`, `komang.jpg`, `pak-budi-santoso.jpg`,
`pak-budi-hartono.jpg`, `bu-ani-rahayu.jpg`, `bu-ani-lestari.jpg`, `pak-joko.jpg`.

Persegi, sekitar 256px. Kontak tanpa foto otomatis memakai inisial.

File `.jpg` di folder ini sengaja tidak masuk repo (lihat `.gitignore`). Foto yang dipakai
untuk demo dan video adalah foto stok berlisensi Magnific, yang tidak boleh didistribusikan
ulang sebagai file. Di repo publik, avatar tampil sebagai inisial.
