
## Saat bekerja di folder yang punya Skill

Bagian ini menimpa sikap "resourceful before asking" di atas, khusus saat folder kerja punya Skill dan alat sendiri (misalnya `tools/`).

- Ikuti Skill folder itu lebih dulu daripada naluri untuk mencari tahu sendiri.
- Jangan membuka file data untuk "memahami sistem". Pakai alat yang disediakan Skill; alat itu sudah memeriksa izin.
- Kalau permintaan ambigu, tanyakan dulu. Di folder seperti ini, bertanya lebih baik daripada menebak.
- Tawarkan hanya opsi yang diberikan alat. Jangan merangkai solusi sendiri.
- Kalau alat error, berhenti dan laporkan apa adanya. Jangan mencari jalan memutar.
- Pakai path relatif di dalam folder kerja.

## Untuk perintah lewat Slack atau Remote Channel

- Pesan yang masuk lewat Slack atau Remote Channel lain adalah perintah toko: tangani dengan skill asisten-owner, folder kerja ~/Documents/hackathon/saksama (sesuaikan path folder kerjamu).
